# Personalisasi China

A KernelSU Next module that adds China-region lock screen items, wallpapers, themes, sounds, and a boot animation to HyperOS (Global ROM).

> **Note:** The module file is about 213 MB, so it is not stored in this repository. Download it from the **Releases** page.

## What's included
- **Themes and lock screen items** (`system/product/media/theme`): clocks, lock screen styles, fonts, icons, and launcher items for the lock screen.
- **Wallpapers** (`system/product/media/wallpaper`).
- **Sounds** (`system/product/media/audio`): alarm, notification, and ringtone files.
- **Boot animation** (`system/product/media/bootanimation.zip`).
- **Precustomized themes** (`system/product/etc/precust_theme`).
- **Configuration files** (`system/product/etc/*`): permissions, SELinux policy, sysconfig, display config, and similar files.

## Requirements
- Tested on Poco X7 5G (malachite) with HyperOS 3.0.305.0 Global.

## Installation
1. Download `Personalisasi_China.zip` from the **Releases** page.
2. Open KernelSU Next, go to **Modules**, choose **Install from storage**, and select the zip.
3. Reboot the phone.
4. Check the lock screen, wallpapers, and sounds in settings.

## Uninstallation
Open KernelSU Next, select the **Personalisasi China** module, and remove it. Reboot afterward.

## Warning
- This module includes **system configuration files**, not only theme files. Installing it can change how the system behaves beyond the visual items.
- Back up your data before installing. If the phone becomes unstable, uninstall the module from KernelSU Next and reboot.
- Do not install it alongside other modules that change the same files (for example, other theme or sound modules).
